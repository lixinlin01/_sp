# NumScript：專門為數字運算設計的微型語言與虛擬機

本專案實作了一個名為 **NumScript** 的微型程式語言。它是一個專門為了數學公式解析與高精度數字運算而設計的領域特定語言 (DSL)。透過本專案，可以深入理解現代編譯器「詞法分析、語法解析、目的碼生成、虛擬機執行」的完整生命週期。

---

## 一、 專案發想與核心目的

因此，**NumScript** 選擇進行「功能瘦身」，將核心完全聚焦於**高精度數字運算與數學公式的解析**上。

### 核心目的
* **學習編譯原理核心**：完整實作從原始碼字串到最終可在虛擬機執行的目的碼（Bytecode）的完整流程。
* **掌握堆疊虛擬機 (Stack VM)**：理解基於堆疊的計算機架構如何利用 `PUSH`、`POP` 以及運算子指令來完成複雜的數學表達式。
* **公式即時解析 (REPL)**：提供類似計算機的互動式介面，能夠即時輸入數學公式並得到高精度的運算結果。

---

## 二、 語言規格與架構設計

* **型態系統**：**純數值型態**。底層所有的數值（包含整數）在運行時一律統一轉為**雙精度浮點數 (Float)** 進行運算，以確保高精度數學計算的一致性。
* **執行模式**：**單趟編譯器 (Single-pass Compiler)**。不產生複雜的抽象語法樹 (AST)，而是在語法解析的同時，直接依序生成堆疊機的虛擬指令。
* **目標檔**：**自定義的 Bytecode (目的碼)**。
* **記憶體管理 (GC)**：**無**。由於只有純數值與全域變數對應表，無動態記憶體配置需求。

### EBNF 語法定義

```ebnf
Program    ::= Statement*
Statement  ::= LetStmt | ExprStmt
LetStmt    ::= "let" Identifier "=" Expr ";"
ExprStmt   ::= Expr ";"

Expr       ::= Term (("+" | "-") Term)*
Term       ::= Factor (("*" | "/" | "%") Factor)*
Factor     ::= Power (("^") Factor)* /* 指數運算 */
Power      ::= Number | Float | Identifier | FuncCall | "(" Expr ")"
FuncCall   ::= Identifier "(" Expr ")"      /* 內建函數呼叫 */
```

## 三、 專案檔案架構與說明
本專案採用模組化設計，共包含 5 個檔案：

### 1. lexer.py (詞法分析器)
- 職責：將使用者輸入的原始碼字串進行掃描，利用正規表達式（Regex）將其切分成具有語意最小單元的 Token 陣列。

- 特色：精準區分浮點數與整數，並自動過濾無效的空白與換行字元。

### 2. compiler.py (編譯器 / 語法解析器)
- 職責：使用遞迴下降分析法 (Recursive Descent Parsing) 檢查 Token 是否符合語法規則。在解析的過程中，嚴格遵循數學的「先乘除後加減」與「括號優先」權重，並直接編譯出對應的堆疊指令。

- 特色：支援指數運算符 ^ 以及內建函數的語法解析（如 sqrt()）。

### 3. vm.py (堆疊虛擬機)
- 職責：模擬中央處理器 (CPU)，內部維護一個資料堆疊 (Data Stack)、一個環境字典 (Environment) 與一個程式計數器 (PC)，依序讀取編譯器生成的 Bytecode 並執行。

- 支援指令：包含堆疊操作 (PUSH, POP, LOAD, STORE)、基礎與進階四則運算 (ADD, SUB, MUL, DIV, MOD, POW)，以及呼叫 Python 底層數學庫的 CALL 指令。

### 4. main.py (主程式進入點與 REPL)
- 職責：專案的啟動器，負責將 Lexer、Compiler 與 VM 串接起來。

- 雙重模式：

    - 腳本模式：讀取外部的 .ns 檔案，一次性執行完畢。

    - 互動模式 (REPL)：提供命令列介面，允許使用者一行一行輸入數學公式，並持續記憶已宣告的變數，就像一個超級計算機。

### 5. example.ns (測試用腳本)
- 職責：提供一個完整的 NumScript 語法範例，用於測試變數宣告、帶變數的複雜代數運算、內建開根號函數 sqrt() 以及指數 ^ 的混合計算。
