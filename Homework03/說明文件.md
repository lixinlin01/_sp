# 天氣小幫手 + 待辦事項 — 說明文件

## 概述

本程式為一個結合**天氣查詢**與**待辦事項**的互動式網頁應用，採用單一 HTML 檔案架構，無需後端伺服器即可執行。透過 Open-Meteo 免費 API 取得即時天氣資料，並依據天氣狀況動態切換頁面色調，提供直覺且美觀的使用體驗。

## 功能說明

### 一、天氣查詢

#### 1.1 縣市快速切換（左側欄）
- 左側列出臺灣 **22 個縣市** 按鈕（六都 + 各縣市）
- 每個按鈕內建精確的 GPS 座標（緯度/經度），點擊後直接向 Open-Meteo API 查詢
- 當前選中的城市按鈕會以高亮顯示

#### 1.2 搜尋框
- 支援輸入城市名稱（中文或英文）進行查詢
- 輸入時會先比對內建的 22 個臺灣縣市，匹配成功則使用本地座標
- 若非臺灣城市，則透過 Open-Meteo Geocoding API 進行地理編碼

#### 1.3 定位功能（📍）
- 點擊右上角 📍 按鈕，瀏覽器請求使用者目前位置
- 成功取得位置後自動查詢當地天氣，並反向地理編碼顯示城市名稱

### 二、天氣顯示資訊

| 項目 | 說明 |
|------|------|
| 天氣圖示 | 根據 WMO 天氣代碼顯示對應的 Emoji（☀️🌧⛈❄️ 等） |
| 溫度 | 當前溫度（°C），大字體置中顯示 |
| 天氣描述 | 晴朗、多雲、陰天、小雨等中文描述 |
| 體感溫度 | 考量風速與濕度的體感溫度 |
| 濕度 | 相對濕度百分比 |
| 風速 | 公里/小時 |

### 三、動態色調主題

頁面背景與毛玻璃卡片顏色會根據天氣自動切換：

| 條件 | 色調 | 色碼 |
|------|------|------|
| 高溫 ≥30°C | 🔴 暖紅 | `#e74c3c → #c0392b` |
| 溫暖 22-30°C | 🟠 橙黃 | `#f39c12 → #e67e22` |
| 舒適 15-22°C | 🟢 綠色 | `#2ecc71 → #27ae60` |
| 涼爽 5-15°C | 🔵 藍色 | `#3498db → #2980b9` |
| 寒冷 ≤5°C | 🩵 冷藍 | `#5dade2 → #2e86c1` |
| 極寒 ≤-5°C | ⬜ 淺藍 | `#aed6f1 → #85c1e9` |
| 夜晚 | ⚫ 深灰 | `#2c3e50 → #1a252f` |
| 雨天 | 🔘 灰藍 | `#5d6d7e → #4a5568` |
| 雪天 | ⚪ 灰白 | `#d5dbdb → #bdc3c7` |
| 雷雨 | 🟣 深紫 | `#4a235a → #2c0e37` |

### 四、天氣建議

根據天氣狀況與溫度提供隨機生活建議，例如：
- 炎熱：「天氣炎熱，多補充水分，小心中暑！」
- 下雨：「☂️ 記得帶傘！」
- 寒冷：「🧥 天氣寒冷，出門多加件衣服！」
- 晴朗：「☀️ 天氣晴朗，適合出門走走！」

### 五、待辦事項（右側欄）

#### 5.1 功能
- **新增**：輸入文字後按 ＋ 或 Enter 新增待辦
- **勾選完成**：點擊圓形勾選框切換完成狀態（文字會加刪除線淡化）
- **刪除**：滑鼠懸停時顯示 ✕ 按鈕，點擊刪除
- **統計**：底部顯示總項目數與完成數

#### 5.2 資料儲存
- 使用瀏覽器 `localStorage` 進行持久化儲存
- 關閉頁面或重新整理後待辦事項不會遺失
- 儲存鍵值為 `weather_todos`

## 技術架構

### 使用技術
- **HTML5**：語意化標籤與結構
- **CSS3**：Flexbox 排版、毛玻璃效果（backdrop-filter）、CSS 動畫（keyframes）、響應式設計（media query）
- **JavaScript (ES2020)**：Async/await、Fetch API、DOM 操作、LocalStorage

### API 依賴
| API | 用途 | 是否需要金鑰 |
|-----|------|:----------:|
| [Open-Meteo](https://open-meteo.com/) | 天氣預報資料（溫度、濕度、風速、天氣代碼） | ❌ 免費無需金鑰 |
| [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) | 城市名稱 ↔ 經緯度轉換 | ❌ 免費無需金鑰 |

### 天氣代碼對照
採用 WMO Weather interpretation codes（WW code）：
- `0` 晴朗、`1-3` 多雲、`45-48` 霧
- `51-57` 毛毛雨、`61-67` 雨、`71-77` 雪
- `80-82` 陣雨、`85-86` 陣雪、`95-99` 雷雨

### 響應式設計
- 螢幕寬度 > 860px：三欄並排顯示
- 螢幕寬度 ≤ 860px：改為垂直排列，城市按鈕改為橫向捲動

## 使用方式

1. 直接用瀏覽器開啟 `weather.html`
2. 允許定位權限可自動取得所在地天氣（可選）
3. 點擊左側縣市按鈕切換天氣
4. 或在搜尋框輸入城市名稱後按查詢
5. 右側待辦事項可自由新增管理

## 注意事項

- 需連接網路以取得天氣資料
- 定位功能僅在 HTTPS 或 localhost 環境下運作
- 部分極偏遠地區的英文名稱可能無法精確匹配地理編碼 API，建議使用中文名稱查詢
