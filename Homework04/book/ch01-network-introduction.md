# 第一章：網路通訊概論與系統程式基礎

## 1.1 什麼是系統程式

系統程式是設計用來管理與操作電腦硬體資源的低階軟體，為上層應用程式提供執行環境。其範疇包括作業系統核心、驅動程式、網路協定棧、編譯器等。網路通訊作為系統程式的核心領域之一，負責在不同主機之間傳遞資料。

## 1.2 網路通訊模型

### 1.2.1 OSI 七層模型
- **第1層 實體層**：定義電氣訊號、纜線、集線器等硬體規格
- **第2層 資料鏈結層**：負責幀（Frame）的傳輸與錯誤檢測（MAC 位址）
- **第3層 網路層**：路由與邏輯定址（IP 位址）
- **第4層 傳輸層**：端對端連線管理（TCP/UDP）
- **第5層 會議層**：建立、管理與終止會話
- **第6層 表現層**：資料格式轉換、加密與壓縮
- **第7層 應用層**：提供應用程式網路服務（HTTP、FTP、DNS）

### 1.2.2 TCP/IP 四層模型
- **應用層**（Application）：HTTP、SSH、DNS、SMTP
- **傳輸層**（Transport）：TCP、UDP
- **網際層**（Internet）：IP、ICMP、ARP
- **網路存取層**（Network Access）：Ethernet、Wi-Fi

## 1.3 封裝與去封裝

當資料從應用層向下傳遞時，每一層會加上自己的標頭（Header），這個過程稱為封裝（Encapsulation）。接收端則反向操作，逐層去除標頭，稱為去封裝（Decapsulation）。

## 1.4 Socket 程式設計概念

Socket（通訊端）是作業系統提供給應用程式的網路程式設計抽象層。對開發者而言，Socket 表現得像一個檔案描述子（File Descriptor），可使用 read/write 系統呼叫進行資料收送。

## 1.5 主機位元組序與網路位元組序

不同架構的 CPU 在記憶體中儲存多位元組資料的方式不同（Big-Endian vs Little-Endian），因此網路通訊統一使用 Big-Endian（網路位元組序）。開發者需使用以下函數進行轉換：

- `htons()` / `htonl()`：主機序轉網路序（16位元 / 32位元）
- `ntohs()` / `ntohl()`：網路序轉主機序（16位元 / 32位元）
